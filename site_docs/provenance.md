# Provenance and rights

## Scientific source integrity

A cloud-drive file locator does not prove which bytes were processed. Mounted storage can retrieve data lazily. Capture cloud identity, source-clock interval, cropped-audio SHA-256, original SRT SHA-256, model version and native execution evidence. Distinguish a cropped excerpt hash from an entire original WAV hash.

## Public versus private

The public fork contains code, synthetic fixtures and *aggregate, qualified* validation claims. Research audio, private meetings, human annotations, individual experimental transcriptions, native logs and unpublished corrections remain in authorized private storage.

The upstream MIT license does not automatically cover source recordings, third-party texts, institutional logos, or research data. The preserved UPSTREAM_README.md exists for source attribution and upstream build reference.

## Release gates

Source branch state, CI passing, CUDA execution, linguistic correctness, privacy clearance and public website deployment are **independent** acceptance states. This site is authorized for public GitHub Pages deployment from the default master branch. Actual live publication must be checked against the completed Pages job. Its styling is INM-inspired, with no official institutional marks. Documentation publication does not approve release of experimental transcription code or research data.
